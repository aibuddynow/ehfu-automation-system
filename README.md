# EHFU Automation System

Production launcher and content assets for **Everything Happens For Us**, part of the Content Empire portfolio.

**Live site:** https://aibuddynow.github.io/ehfu-automation-system/

## What's inside

| Path | Purpose |
|---|---|
| `index.html` | Production launcher (GitHub Pages homepage) |
| `invideo-prompts/` | Video prompt library for invideo AI |
| `pins/ehfu/` | Pinterest pin copy and build script |

## Deploy

Pushes to `main` publish automatically via GitHub Pages (root folder).
